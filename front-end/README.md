# Front-End Module — Studio Dori

This directory contains the user interface, React components, Next.js page layouts, global context state providers, and internationalization translations.

## Structure
- `src/app/`: Next.js App Router pages (Home, Shop, Product Detail, Checkout, Login, Customer Account, Admin Portal, About, Journal, Contact).
- `src/components/`: Reusable editorial UI components (Header, Footer, ProductCard, CartDrawer, WishlistDrawer, QuickViewModal, SearchOverlay, ShopTheLook).
- `src/context/`: React context providers (AuthContext, CartContext, WishlistContext, LanguageContext).
- `src/lib/i18n/`: Multi-language dictionary (`EN`, `JA`, `FR`, `DE`, `ES`).
- `src/app/globals.css`: Color tokens, Garamond & Manrope typography styling.
